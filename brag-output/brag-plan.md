# Brag Plan: Topsoil (Real Application Edition)

## What is this app?
Topsoil turns the MacBook camera cutout into a live, borderless dashboard for coding agents (Claude, Codex, Cursor), music controls, active timers, and files — built natively with Swift 6 and SwiftUI, zero Electron, and completely local by default.
